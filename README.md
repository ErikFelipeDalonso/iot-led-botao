# LED + Botão

**Discente:** Erik Felipe de Andrade Dalonso

**Docente:** Amanda Paul Dull

Este repositório contém a atividade prática de IoT utilizando um Arduino UNO, um botão e um LED.

## Enunciado: LED + Botão

A atividade consiste em utilizar um botão para controlar um LED.

Ao pressionar o botão, o Arduino identifica o comando e aciona o LED. Ao soltar o botão, o LED é desligado.

| Qtd | Componente |
| --- | --- |
| 1 | Placa Arduino UNO |
| 1 | Cabo USB |
| 1 | Protoboard |
| 1 | Resistor de 200 Ω ou 220 Ω |
| 1 | Resistor de 10 kΩ |
| 1 | Botão tipo Push Button |
| 1 | LED vermelho difuso de 5 mm |
| — | Fios de jumper macho-macho |

## Como foi feita a atividade

Primeiramente, foi montado o circuito utilizando o Arduino UNO e a protoboard.

O LED foi conectado ao circuito utilizando um resistor para limitar a corrente. O botão também foi conectado à protoboard, juntamente com um resistor para garantir o funcionamento correto da entrada.

Após a montagem do circuito, foi desenvolvido um programa para que o Arduino verificasse o estado do botão e controlasse o LED.

Quando o botão é pressionado, o LED acende. Quando o botão é solto, o LED apaga.
